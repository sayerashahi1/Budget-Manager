
# PennyWise — Budget Manager

PennyWise is a Java desktop application that helps users manage
their personal finances by tracking income and expenses.

## Features

- Personalized welcome screen
- Financial dashboard with balance, income, and expense totals
- Add income and expense transactions
- Transaction history table
- Delete selected transactions
- Automatic balance calculations
- CSV file storage to preserve transactions between sessions
- Input validation and confirmation messages

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- ArrayList collections
- File handling
- CSV data storage

## Project Structure

Budget Manager/
├── Main.java
├── Dashboard.java
├── Transaction.java
├── BudgetManager.java
├── README.md
└── transactions.csv (created automatically)

## How to Run

1. Install a Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Open Main.java.
4. Click Run above the main method.

Transactions are saved in transactions.csv in the application's
working directory.
